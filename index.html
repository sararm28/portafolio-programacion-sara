Proyectos

Mundo Ciencia

Objetivo: Plataforma para una feria escolar de ciencias donde los estudiantes se registran, publican sus experimentos y consultan su actividad, con un panel para administradores.

Tecnologías: PHP, MySQL, HTML, CSS, JavaScript

Mi aporte: Diseñé la base de datos (usuarios, experimentos e historiales) y programé el registro, el inicio de sesión y la gestión de experimentos. También construí las vistas con HTML y CSS.

Aprendizaje: Aprendí a conectar PHP con MySQL, a manejar sesiones y roles de usuario y a proteger formularios con consultas preparadas. Mejoraría agregando búsqueda de experimentos por categoría.

Aureo — Landing de joyería

Objetivo: Página de presentación para una marca de joyería femenina, con colecciones de collares, aretes y pulseras, sección de nosotros y contacto.

Tecnologías: HTML, CSS, JavaScript

Mi aporte: Desarrollé el proyecto de forma individual: la estructura en HTML, los estilos en CSS y las funciones en JavaScript (menú móvil, filtro de productos, contadores y validación del formulario).

Aprendizaje: Aprendí a usar Flexbox y Grid para que la página se adapte a celulares y a manipular el DOM con JavaScript. Mejoraría conectando el formulario a un servicio de correo real.
